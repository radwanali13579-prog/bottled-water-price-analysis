# Bottled Water Price Analysis in Malaysia

**Engineering Statistics | QMQ27103**  
**Universiti Malaysia Perlis (UniMAP)**  
**Academic Session:** 2026/2027 – Semester 1

## Project Overview
This project investigates how bottled water prices vary by brand and bottle size in Malaysia, with additional comparisons across online stores.

The main objective is to understand price variation and identify more affordable options using statistical analysis and Microsoft Excel.

## Research Question
How do bottled water prices vary by brand and bottle size in Malaysia?

## Dataset
- **Observations:** 150 product–store records
- **Location:** Malaysia
- **Focus:** Brand, bottle size, price, store, and price per litre

## Excel Analysis
The project includes:
- **Bar Chart:** Number of product listings by brand
- **Histogram:** Distribution of bottled water prices per litre
- **Scatter Plot:** Comparison of selected top-five and bottom-five products
- **Box Plot:** Comparison of price-per-litre distributions across stores
- **PivotTables and formulas:** Data summaries and price-per-litre calculations

## Key Skills
- Microsoft Excel
- Data organization and cleaning
- PivotTables
- Statistical analysis
- Data visualization
- Interpretation and presentation of results

## Project Files
Project materials are provided in this repository, including the dataset, statistical report, and research poster.

## Learning Outcomes
This project strengthened my ability to organize data, create statistical summaries, compare distributions, interpret variability, and communicate findings clearly.
